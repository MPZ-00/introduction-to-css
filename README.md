# Introduction to CSS

A hands-on CSS reference built with [Hugo](https://gohugo.io). Each topic has live demos baked in: the example running live next to its source. No external sandbox, no extra tabs.

Live at **[introduction-to-css.mpz-00.me](https://introduction-to-css.mpz-00.me)**

## Topics covered

- Selectors
- Box Model
- Colors
- Typography
- Flexbox
- Grid
- Animations
- Positioning

## Run locally

```bash
hugo server --buildDrafts
```

Then open `http://localhost:1313`.

## Build

```bash
hugo build
```

Output goes to `public/`.
